# SubterfugeBot

自定义 bot 开发请阅读 [详细接口与开发指南](DEVELOPING.md)，并参考随包的 `examples/minimal-bot/`。接口的准确类型以 `plugin-sdk/types/` 为准。

安装 Node.js 22.13 或更新版本后运行 `start.sh`（macOS/Linux）或 `start.cmd`（Windows），打开终端打印的本机控制台地址。默认优先使用端口 4400，占用时自动选择可用端口；启动失败时 Windows 窗口保留错误提示。可用 `node launch.mjs --console 4401` 指定其他端口。首次启动八席均未绑定、保持暂停；从游戏大厅绑定后自行启动。不配置模型时也能自主规划；选择 Codex 模型需要另行安装并登录 Codex CLI。

`plugins/hybrid/` 包含官方 hybrid 的完整策略源码，可修改提示词、战略、外交与前台协同逻辑。复制文件夹创建自己的 bot 时，修改清单 ID，并在实例工厂中使用对应身份和记录前缀。公共计算与执行服务由 `plugin-sdk/` 定义，源码不包含宿主实现。

编辑后在本目录运行：

```sh
node tools/check-plugin.mjs plugins/hybrid
```

此命令使用随包提供的 TypeScript 与 esbuild 编译器，先检查类型，再检查插件接口，不需要 npm install，也不连接真实游戏或调用模型。插件校验会执行本机可信代码，不能用于不信任的插件。

控制台“扫描插件目录”支持选择插件文件夹或上级目录。首次启动会通过同一加载器安装官方 hybrid；后续按安装快照运行，编辑源码不会悄悄影响运行中席位。先暂停并切换使用该插件的所有席位，再加载更新；成功后重新选择并启动。

`data/` 保存本机私有设置、笔记、回执和运行记录，不随发布包分发。`runtime/` 与 `web/` 是打包宿主，启动会检测文件变化；该检查用于发现误改，不保证阻止本机所有者修改程序。`plugins/` 不参与宿主完整性校验。此分发包包含当前平台的编译器程序，请使用与操作系统和 CPU 匹配的版本。
