# 研究资料边界

研究用于说明固定规则来源和算法选择，不是产品待办或当前版本演化日志。

- [样本与静态提取](../reverse-engineering.md)：来源、哈希与重建流程。
- [规则来源与本地差异](../rules/05-versions-and-sources.md)：参考基线和现行玩法分工。
- [地图选择的研究边界](map-selection.md)：静态代理指标及其局限。
- [固定样本资料索引](data/audit-manifest.json)：规则、资产、教程元数据与参考函数样本；仅表示来源清单，不声明当前产品完成度。

原始 APK、解包内容、格式化 bundle 和实验数据由合法持有者在本地 research 目录保存，不随源码分发。规则 JSON 中的来源定位和参考配置是可追溯数据，不应为了让当前玩法看似完全一致而改写。

具体研究实验、对局和性能报告不承担当前使用说明的职责；新功能以现行产品约定、源码和协议为准。
