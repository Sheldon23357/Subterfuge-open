# 音乐与操作音效

## 资源

音频清单位于 `packages/client/public/audio/manifest.json`，包括五首原创代码编曲/合成配乐和十八个操作音效。浏览器优先 OGG，兼容回退 MP3；母带与编码文件分别保存来源，不承诺所有设备的压缩解码循环都无缝。

## 生命周期

实验室和玩家页共用 `game-audio.ts` 与 AudioSettings。音乐、音效独立音量与静音，支持选曲、轮播和单曲循环；默认音量 25%。

只在可信点击或键盘手势后开始。页面隐藏/卸载暂停，切歌淡入淡出；同来源标签页用短租约避免叠播，不同域名或端口不能靠 localStorage 跨来源互斥。最多同时五个效果声音，不积压补播。

常用按钮及打开弹窗音效提前加载并解码为 Web Audio 缓冲，打开音在点击处理时触发，不等待弹窗渲染。尚未加载或音频上下文未解锁时跳过，不在稍后补播；不支持 Web Audio 的环境沿用媒体元素播放。关闭弹窗、收起面板和关闭单位信息静音。

## 事件语义

按钮点击提供短反馈，地图上的据点、单位选择及取消选中静音。实际操作音等待服务器确认；自动或实时推进后的权威状态进入新世界日时播放日期推进音效，初次加载、重复状态、开启自动推进、手动单步及时间预览不触发该音效。一次状态更新跨过多天时只播放一次，不补播遗漏日期。预约登记只发确认音，不冒充出航；预览、读状态或管理员推进不冒充真实舰队动作。

通知只使用授权过滤数据，初次历史分页静音，新增按事件 ID 去重，重要警报限频；自己发送的消息不播放收信提示。没有明确胜负事实时不播放素材中的终局短句。

音频不读取隐藏事件，不影响权威游戏推进。设备自动播放、解码和主观听感需要分别检查，静态资源存在不能代表实际设备体验已验证。
