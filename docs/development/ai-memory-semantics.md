# 战略、笔记与提醒

## 数据职责

程序维护授权事实、实际结算、已接受预约和执行账本；模型维护战略解释与跨轮认知。笔记不是当前地图的替代品，也不能将预测成功写成已执行。

战略判断独立常驻，最多 1,000 UTF-16 字符，应包含当前目标、主要威胁与机会、路线理由和重新评估条件。指挥官已确认指令是另一个有版本的权威领域，模型战略不能反向覆盖它。

## 笔记

笔记类型为 fact、plan、agreement、note，具有稳定 ID、正文、优先级、正文更新时间和有效期。正文保存必要参数、条件及判断，不复制整张地图或完整推演。

- 当前有效笔记最多 32 条，正文合计最多 12,000 UTF-16 字符。
- 优先级为 high、medium、low，缺省 medium。
- 超限先淘汰最低等级中正文更新时间最早者；同时间按稳定 ID 排序。
- 只改优先级不刷新正文时间；更新省略字段沿用当前有效记录的对应值。
- `expiresWorldDay: null` 为长期保留，有限有效期使用未来绝对世界日。
- notebook 空参数读取当前有效笔记，不读取历史归档。
- 后台保留审计不等于允许模型跨轮 recall；失效事实不能通过旧引用恢复成当前事实。

有效事实、报告、预测和推断须标明依据，不补未知为零。删除不表示履约或战略目标完成。

## 提醒

提醒只要求到时重新判断，不执行命令，也不保证模型恰时完成。bot 不通过提醒登记预约；玩家可手动使用服务器预约。

`reminders` 支持 set、cancel、complete；complete 只接受已到期 ID，提前处理或失效的事项用 cancel。最多 16 项，未来 1,008 世界日内，正文最多 500 字符，触发时点必须为整数绝对世界日。到期后不因展示自动消费，须明确处理。

事实通道已确认的抵达或操作结果由程序提供，不要求模型额外设置“猜测抵达”提醒。历史舰队引用不等于该舰队仍存在或仍可作为当前命令目标。

## 保存与指挥官清理

notebook、reminders 可在轮中保存；finish 在同一事务提交本轮本地更新并结束。未完成事项和 unknown 执行保留，不能为结束轮次伪造成功。

finish 可提交当前已确认指令中实际完成的完整原文条款及本轮事实依据，由程序核验后清理。不能新增、改写条款，也不能清除仍在途、仅预测成功或持续有效的约束。讨论和普通决策的原始记录、当前状态和归档按当前房间与玩家隔离。
