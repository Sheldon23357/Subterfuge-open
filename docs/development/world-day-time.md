# 世界时间契约

## 单位

玩家和模型中的第 N 天就是 tick N，第 0 天开局。1 tick = 1 世界日 = 600 内部规则秒 = 10 内部规则分钟；经过时长从零计算，可为小数。

`TICKS_PER_DAY=144` 是参考经济周期常量，不是玩家世界日。参考经济日均速率除以 144 才是每世界日均速率；生产和护盾仍按真实整数批次及周期结算。

## 字段与输入

| 字段 | 含义 |
| --- | --- |
| view.tick | 整数世界日 |
| secondsSinceLastTick | 当前日内规则秒 |
| *Seconds / atSeconds | 内部规则秒，显示世界日除以 600 |
| *Minutes / arrivalMinutes | 内部规则分钟，显示世界日除以 10 |
| issueTick / targetTick | 对应的绝对逻辑时点，是否允许小数取决于具体操作 |
| UTC / Date.now / 网络超时 | 现实时间，不作游戏日换算 |

完整观察时点为 `view.tick + secondsSinceLastTick / 600`。普通抵达、预测与经过时长保留小数，不用整数 arrivalTick 替代精确 ETA。

自动预约、明确指定准备结束时点和提醒须落在整数绝对世界日，不静默取整。例如当前 1.25 天，希望第 3 天出发，准备时长为 1.75 天；直接延迟两天会落在 3.25 天，真实提交拒绝。省略延迟或指定零延迟的出兵立即出发，无默认准备期。

模型 launch 的 delayWorldDays 是显式延迟时长，范围 0–144 世界日，精度最多 1/600 日，由程序转换为内部规则秒。bot 不登记或取消预约；未来行动在后续唤醒时依据当前事实重新判断。玩家仍可手动预约。

## 展示

显示最多六位小数，近似文本不能替代原始时间。笔记过期等非自动执行时间不强制整数日。通知和活动日志按各自来源转换，不能对已经归一化的时点重复减一 tick。

纯转换位于 `packages/contracts/src/world-time.ts`，不更改引擎推进、战斗或生产，也不为展示改变观察 revision。真实大厅倒计时、模型超时、轮询、动画和诊断耗时保持现实单位。
