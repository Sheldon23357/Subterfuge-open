# 当前功能范围

本页是产品范围约定。规则库包含的能力不自动代表产品入口开放；恢复关闭项需要用户明确要求。

## 游戏与界面

| 功能 | 当前范围 |
| --- | --- |
| 对局 | 2–10 人，个人采矿或统治；新建对局仅允许 `teamSize: 0` |
| 玩家网页 | 完整海图、单位详情、部署、预约、聊天、情报、战报、历史、未来预览和终局排名 |
| 大厅加入 | 从房间列表直接加入或返回已有席位；不提供网页加入码输入、展示及复制入口，底层房间标识供 AI、接口和运维使用 |
| 已结束对局 | 大厅中默认收起，按实际结束时间保留最近 5 局；超出的旧终局自动删除房间数据，未结束和恢复失败的房间不参与自动删除 |
| 对局时间模式 | 创建时选择实时或回合；实时每 tick 1–3600 秒，默认 10 秒；回合在全部存活玩家／AI 就绪后推进一个 tick |
| 出兵与返航 | 玩家出兵仅支持立即出发，不提供预约出发或未来预览中的出兵入口；舰队可返航一次至出发据点，兵力减半向下取整；到达敌占据点正常攻击 |
| 外交协议与关系 | 服务器据点停战固定 100 tick、攻击第三方固定 200 tick，夹击双方各占领敌方任意一个据点，支持签署补贴和双方回执；左侧“关系”位于“战损”之后，详见[外交协议](diplomacy-agreements.md) |
| 战损矩阵 | 所有玩家可见服务器发送的全局累计兵力战损；战斗详情与地图继续遵守各席位迷雾权限 |
| 实验室 | 按当前席位迷雾显示；另外提供管理员席位切换、推进、新局和导入导出 |
| OB 聊天 | 本机实验室 OB 视角只读查看全部玩家的公开、私聊和群聊记录；不含指挥官私聊 |
| 组队 | 关闭，不提供组队选择、共享视野或团队胜利入口 |
| 资助、撤销资助 | 产品网页和官方 bot 工具不开放；底层规则及参考数据保留 |
| 主动投降 | 隐藏；不影响资产耗尽、不活跃等规则淘汰 |
| 专家系统 | 移除女王、公主、招募、晋升、技能、运输和俘虏机制 |
| 可玩教程、自定义规则对局 | 不在实现范围，除实时 tick 时长外，不开放自定义牌堆、规则覆盖或其他时间倍率配置 |
| 音频 | 共用音乐与操作音效设置，遵守浏览器用户手势限制 |

普通玩家不能使用管理员新局、真实时钟推进、权威导出或任意席位数据。终局公开地图按服务端终局投影执行。经济预测不额外添加重复警告或标签；必要未知和操作错误仍须清楚表达。

## 单位与淘汰

当前玩法标识为 `diplomacy-core-v1`。单位只有据点和普通兵力舰队；出兵必须携带正数兵力，目的地只能是据点。战斗、生产、护盾和声呐采用普通规则。

玩家没有未毁的己方据点，且没有仍使用、携带正数兵力的己方舰队时淘汰；丢失最后据点后仍可由剩余舰队反攻。采矿、统治和最后幸存者胜利继续使用各自终局规则；外交协议、双向信任及回执按[外交规则](diplomacy-agreements.md)执行。

新建实时对局连续现实时间 3 小时未签到自动退出，不清零已有矿量；退出者仍按出局状态排名。具体计时及历史对局边界见[不活跃规则](realtime-clock.md#不活跃)。

## 新局地图

默认使用数量优先筛选，可选择原版候选评分。两者均从连续 500 个候选中选择，保留原候选坐标、出生点和己方初始建筑，中立建筑按目标比例分配。每人五个初始据点，同局统一为两电厂三工厂或三电厂两工厂，全图初始电厂目标比例为 45%，电厂数量按四舍五入取整。一处普通出生据点初始零兵，另外四处各 40 兵；中立点初始零兵。详见[地图生成](map-generation.md)。

## bot

官方分层协同（hybrid）以完整源码插件随包提供，由目录加载器接入；宿主没有内置策略回退。本机控制台支持扫描本地 TypeScript 插件文件夹、基本接口校验和每席独立选择，源码构建也可显式注册自定义完整 AI，实现与接入方式见[AI 本地插件与源码扩展](ai-extensions.md)。配置模型时，后台模型负责战略、外交及指挥官要求转译，前台负责本地战术搜索和执行；不配置模型时，前台自主决策。共用调度、授权事实、执行器、回执、存储与恢复基础，详见[分层协同 bot](hybrid-bot-guide.md)。固定控制台预置八个槽位，未绑定可配置但不能启动。绑定后默认暂停，启用、自动推进和机械保活分别有自己的授权条件。

本机控制台在当前标签页进入大厅选择本人席位或可领取空位，授权后自动返回并完成连接，不另开授权窗口；读取列表不自动占位。网页隐藏大厅地址，不提供更换大厅和高级手动连接入口。大厅显示 bot 连接名称及失联过期状态，连接不等于启动。公网连接要求可信 HTTPS，配置文件模式不开放网页改绑。详见[本机控制台](ai-runtime.md#本机控制台)。

模型和策略按槽位保存，私有历史按服务器、房间与玩家隔离。切换对局不合并旧局笔记。模型调用和 Token 用量用于统计，不设置调用总量配额；运行时仍有并发、上下文和时间保护。未配置模型时不解析新的自然语言要求，也不自动开展模型外交；已发布约束和未决操作继续有效。详见[运行说明](ai-runtime.md)和[模式架构](controller-bot-modes.md)。

## 协议与计算归属

公开执行器协议为 `/player/v2`，大厅为 `/lobby/v2`，托管 AI 管理为 `/ai/v2`。身份、命令、事件、租约与实际结算由服务器维护。

预测、比较、路线和部署预览、抵达估算、进攻候选在控制器或浏览器本地计算，只使用授权观察。进攻初筛和推荐能力保留，模型负责最终战略取舍。执行器通过事件轮询、分页快照和批量命令查账接入，就绪是正常命令种类。接口清单见[玩家接口](player-api.md)。

## 持续运行

实时对局的即时行动不因跨 tick、旧观察版本或旧依据摘要本身被拒绝，按服务器当前状态校验合法性、资源、归属、人工优先级及控制权限。非实时对局、预约与就绪上报保留严格的版本和时间约束。

实时游戏按保存的时钟运行；测试自动推进由服务端协调当前启用席位的就绪状态，不依赖浏览器保持打开。重启、导入和恢复后的运行意图须核对并显式恢复。正常对局不得为文档整理、升级或测试便利而清空。开发存档与恢复约定见 [AGENTS.md](../../AGENTS.md)及[联动存档](linked-checkpoints.md)。
