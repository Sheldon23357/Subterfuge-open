# 席位信任与玩法设计

## 范围与状态

席位关系由服务器按两个独立方向维护，开局历史信任为 0，新局不继承，换控制器不重置。协议主规则见[服务器外交协议](diplomacy-agreements.md)。当前信任不改变实际战斗、护盾、生产或航速；高低信任下的守备、谈判取舍和攻击目标选择由 bot 战略判断处理，不使用服务器概率强制接受协议。

`T(A,B) = clamp(R(A,B) - P(A,B) - C(A,B), -100, 100)`

R 是历史信任，P 是当前边界压力，C 是当前竞争压力。历史分在事件后截断至 −100～100，当前值也在该范围。历史变化和压力均保留四分之一点精度，界面最多两位小数。局势压力可随现状解除，不反复扣历史分；两个方向不要求相等。

## 历史信任结算

| 权威事实 | 方向 | 变化 |
| --- | --- | --- |
| 正式协议签署 | 双方对另一方 | 各 +2，同一对席位滚动 72 tick 最多一次 |
| 据点停战完成 | 双方对另一方 | 各 +6，同一对席位滚动 100 tick 最多一次 |
| 夹击个人达标 | 合作方对履约方 | +10，实际占领共同敌人任意一个据点，每合同每人一次 |
| 夹击到期本人未达标 | 合作方对未完成方 | −10，本人没有实际占领共同敌人据点 |
| 在敌方据点发生实际攻击 | 被攻击方对主动攻击方 | −6，同方向滚动 24 tick 最多一次 |
| 普通据点被占领 | 原主对占领者 | 额外 −4，同点同方向滚动 24 tick 去重 |
| 矿点被占领 | 原主对占领者 | 额外 −8，替代普通占领扣分 |
| 停战违约 | 守约方对违约方 | 额外 −roundQuarter(30 + max(0, 事前当前信任) / 2) |
| 拒绝、撤回、反提、提案超时、签署失败 | 无 | 0 |
| 外部原因终止 | 无新增欠额处罚 | 保留此前事实 |
| 矿产补贴 | 无独立奖励 | 0 |

停战完成奖励还要求：到期时至少一条被协议同时覆盖两端的实际边界，已经连续受保护 24 tick。失去边界会清除该边的连续计时；恢复后重新起算。没有实际接触的停战仍合法，不获得履约分。合同完成与是否获得冷却内奖励分别表达。

攻击和占领的普通扣分，同方向滚动 24 tick 合计最多 20；违约与欠额不受此上限保护。一次交战违反多份重叠停战，各合同分别记录终态，但只追加一次违约处罚。违约基数取整笔交战前的有效信任，不能先扣本次攻击、占领或重算失矿排名再计算。

途中舰队战不完成夹击占领目标，但不能仅凭引擎 attacker 字段推断主动挑衅，首版不因此扣普通攻击分。出兵、预测和舰队消失也不产生实际攻击分。夹击占领履约与信任占领处罚各自按规则去重，不互相替代。签署前战果不回填，同一双方同一共同目标不能并存多份有效夹击合同。

## 边界压力

地图公开坐标决定固定邻接图：每点连环绕地图距离最近的三个其他点，任一方向选中即形成无向边，去重；等距按据点身份排序。它不使用声呐、兵力或 AI 分区。

双方各拥有未毁的边两端时形成边界；中立或第三方端点不算该双方边界。有效停战清单同时覆盖两端，则该边不计压力。只保护单端不能消除整条边界压力。

未保护边界数为 n，`P = min(12, 3 × ceil(n / 3))`。0 条为 0，1～3 条为 3，4～6 为 6，7～9 为 9，10 条及以上为 12。P 双向相同，R 仍可不同。据点归属、毁坏和合同状态变化立即反映当前压力，不留下反复扣分的历史。

## 经济竞争排名

服务器以同一当前权威切面比较所有存活席位，复用公开经济口径：矿产库存（补贴及失矿后余额）、总兵力（驻军和有效舰队携带量）、未毁据点数量。存量舰数按兵力解释，不用可拆分的舰队支数，不计预测产兵和计划占领。

三项分别按降序排名，并列取平均。n 个存活席位中的名次 r 转为 `p = (n - r) / (n - 1)`，最高 1、最低 0、全部并列为 0.5；n≤1 时竞争压力为 0。

`S = 0.5 × p矿量 + 0.3 × p兵力 + 0.2 × p据点`

S 降序生成综合排名，并列仍取平均。采矿与统治使用相同权重；这是当前资产排名，不是胜率。

`C(A,B) = roundQuarter(20 × max(0, 2S(B) - 1) + 10 × max(0, 2min(S(A), S(B)) - 1))`

竞争压力范围 0～30：对领先者有压力，双方处于前列时另有相互竞争，因此可双向不同。全员资产三项完全相等时压力为 0。例：S(A)=0.9、S(B)=0.8，A 对 B 为 18，B 对 A 为 22。少量资产变化也可能改变排名，当前不按资产差距平滑。

每次授权观察从当前已结算资产即时复算，不缓存六日旧值。补贴、失矿、占领、淘汰变化后下一观察反映新值，不回填过去处罚。先固定事前信任，再处理完整事件，再重算当前压力；补贴收款后即使历史加 2，当前信任也可能因竞争加压下降。

## 和平恢复

每对席位记录最后一次明确的据点敌对交战。连续 72 tick 没有新敌对后，每满 24 tick，双方负历史信任恢复 1，最多到 0。首个恢复点为最后敌对后 96 tick；开局从本局起点计时。新敌对重置计时，暂停和恢复不重置世界时钟。

正历史信任不自动上涨或衰减；欠额扣分不视为军事敌对事件，边界和排名压力不会被和平计时抹除。没有低信任禁谈判、自动阵营或强制盟约；绝境中的有限交易始终允许。

## 左侧关系标签

游戏左侧顺序为“聊天、计分板、战损、关系”。关系表按当前授权席位展示“我对其信任”和“其对我信任”，悬停显示历史、边界、竞争分解。未授权或不可用显示缺失，不补成 0；实验室切席位按新权限读取，OB 使用全局有向矩阵，行玩家对列玩家的信任分别展示，对角线不计信任；全局投影仅用于有权获取完整对局的本机实验室，普通玩家投影仍只含与自身有关的双向关系。

表格始终使用当前权威值，不跟随地图历史或未来推演。其下提供正式协议与回执、发起、同意、拒绝、反提和撤回操作。条款展示固定时限、各自占领目标和补贴方向；历史、未来、只读及非活动席位不开放提交。标签使用既有 tablist、tab、tabpanel 关联，窄面板可滚动。

## bot 与能力边界

程序向后台简报提供双向关系、竞争排名、当前合同、个人责任和实际回执。模型解释战略意义并决定谈判、攻击与风险承担；程序不根据高信任自动接受、根据低信任自动攻击，也不改战斗结算。已签合同的默认守约策略及个人履约目标由程序维护，详见[服务器外交协议](diplomacy-agreements.md#bot提示词与控制台)。

担保冻结、退款、关系决定战力或额外全域停战均未开放。信任规则减少重复计分，不保证消除多席位串通；平衡效果需要持续对局观察。验证记录放 outputs，不作为本页永久功能结论。
