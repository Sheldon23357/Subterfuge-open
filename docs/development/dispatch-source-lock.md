# 同世界日来源调度锁

同一玩家、来源据点和权威世界日内，首次分兵到多个目标允许；首次编辑既有待发调度或成功撤销出兵后，来源锁定至下一世界日。

- 锁定期间不能从该来源新增或编辑出兵，包括未来预约；仍可撤销已有待发和预约。
- 按相同航线重新下令、原样改兵量、未来修改既有调度均按服务端实际语义识别，不因换命令 ID 变成新来源。
- 取消预约按实际受影响来源确定锁，级联取消涉及来源一起处理。
- 已接受未来预约不会因后来加锁自动撤销，到期仍按合法性与人工优先级执行。
- 同 key 的准确幂等重放不新增修改，明确失败不创建锁；不同 ID 原样下令是新操作。
- 锁随权威状态持久化，重启、失租、人工介入和观察版本改变不清除，只有世界日前进过期。

观察返回 dispatchLocks，拒绝使用 DISPATCH_SOURCE_LOCKED。网页说明下一日恢复及仍可撤销；程序化候选提前剪枝，真实执行仍由服务器校验。批次逐项执行，锁或 unknown 不回滚已接受项，也不强制 ready 或跳日。

该规则限制同来源同日出兵反复，不替代其他命令的合法性和策略收益判断。
