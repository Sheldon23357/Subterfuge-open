# 浏览器客户端

## 入口与权限

实验室、认证玩家和大厅复用完整游戏海图与操作组件。实验室默认 http://127.0.0.1:4310 ，玩家直连默认 http://127.0.0.1:4311 ，多房间大厅默认 http://127.0.0.1:4312 。

大厅按房间在同源浏览器本地持久保存加入凭据及最近进入的身份；关闭标签页后重新打开，可继续当前对局，或从房间列表以原身份进入已满员、已开局的房间。已打开的标签页保留自己的当前身份。主动断开清除自动继续记录，但保留该房间的加入凭据，供再次进入时恢复席位。直接手动输入的玩家凭据仍只保存在当前标签页会话。凭据不写 URL 或日志；清除站点数据、更换浏览器或访问源不会恢复原身份。服务端按当前身份发送迷雾投影，客户端不能靠角色按钮获得全图。实验室可切席位和使用管理员工具，普通玩家隐藏这些能力。产品操作范围见[功能范围](feature-availability.md)。

大厅启动时先显示随 HTML 返回的深海背景加载面板，不等待主样式与应用脚本；主样式非阻塞下载后切换为正常大厅，启动资源加载失败或超过 30 秒时提供“重新加载”按钮。应用启动后等待背景图片和首批房间列表完成加载。背景使用预加载的压缩 JPG；加载失败或超过 15 秒时恢复可操作大厅并提供图片重试，网络恢复后仍可刷新房间列表。

创建房间可选择实时模式并设置每 tick 秒数，或选择回合模式。回合局正式开始后，玩家页显示当前 tick、存活席位就绪数与“本回合就绪／取消就绪”；由 AI 控制的席位使用其执行器就绪声明，玩家按钮禁用。

作战大厅主列表显示未结束房间；已结束对局放在默认收起的折叠列表，只显示最近 5 局。恢复中和恢复失败的房间显示对应状态并禁用进入，后台继续提供其他房间。保留与删除规则见[大厅生命周期](lobby-lifecycle.md#恢复与终局保留)。

玩家页链接采用 `/player.html?room=ABC123&seat=2`，`room` 为房间标识，`seat` 为从 1 开始的原大厅席位编号，开局压缩后的游戏席位不改变链接。浏览器按房间与席位分别保存身份，支持多标签页查看不同房间或席位。URL 只负责定位，进入前以服务器核验本地凭据；没有该席位凭据时提示返回大厅或从对应 bot 打开，不自动领取或切换其他席位。旧的无参数玩家页仍可恢复最近身份，核验后自动补全链接。凭据不出现在 URL 中，复制链接不授予席位权限。

## 海图与单位

海图为环绕空间，支持拖动、缩放、单位选择、航线与详情。位置、兵力、护盾、生产、矿量与待执行状态来自当前 DTO，未知不显示为零。据点名在日志、笔记和讨论中可定位，仅使用当前客户端合法地图。

部署支持来源、目标和正数兵力；路线预览与抵达估算在浏览器本地基于授权观察计算。服务器确认后更新真实状态，不把预览当作执行。

即时出兵在服务器内只产生一次出发状态事件，实时播报显示一条“舰队出发”，时间为实际下令时刻；命令审计仍保留原始指令。显式延迟出航才分别记录出兵指令和实际出发。

部署面板仅提供正数舰数选择，点击“立即出兵”后立即出发，不提供预约出发日期。未来预览只能查看局势与路线，不能打开出兵面板或提交出兵；须返回当前时间操作。历史数据中的显式延迟出航倒计时严格大于零才可撤回；零秒仍显示 waiting 不代表可撤回。当前观察中的 departureCommitted 等规则状态优先于动画或四舍五入文字。调度修改遵守[来源锁](dispatch-source-lock.md)。

己方舰队详情提供“返航”：返回出发据点，舰数立即减半向下取整。按钮提示损失与次数限制；已返航或无返航资格的舰队禁用。到达时若出发据点被敌方占领，则按正常攻击结算；沿途仍可交战。

## 时间、预约与历史

时间轴区分当前、未来条件预览与实际历史。未来预览在 Worker 内计算，不推进世界。历史按选中时点的原始命令和玩家视野重建；固定历史选择不会因实时推进自动跳走。取消或切席位终止过时计算，缓存有界。

开矿、护盾等非出兵操作仍可预约至整数绝对世界日；已登记预约、草案、在途舰队分别展示，避免重复计兵。玩家出兵适配层拒绝预约或显式延迟出兵请求，未来部署条件推演与存量预约结算保留。成功登记不表示已经出航，到期是否执行以权威记录为准。单位说明见[世界时间](world-day-time.md)。

## 通信与控制

左侧通信面板按聊天、计分板、战损、关系排列，不显示航海日志标签；授权通知与警报音效仍在后台更新。

“关系”标签展示当前席位两个独立方向的信任值，悬停显示历史、边界和竞争分解。下方外交协议区在标题旁提供发起入口，分别显示停战与夹击生效名额；“进行中”按待我签署、等待对方、履约中分组，“协议记录”展示近期结束结果，“结算动态”展示近期协议回执。协议卡片列出停战据点或共同目标、固定时限、截止时间、双方独立的折算战损承诺及实际进度、签署补贴；可接受、拒绝、撤回或修改条款并反提。合同与回执只对参与双方可见。切席位刷新权限，关系不跟随历史和未来预览，预览及只读时不能提交。详见[关系规则](seat-trust.md#左侧关系标签)和[外交协议](diplomacy-agreements.md)。

计分板右侧的“战损”标签展示所有玩家的 N×N 全局累计兵力战损矩阵，由服务器从完整实际战斗记录累计并发送给所有玩家。纵轴是承受损失方，横轴是造成损失方；双方损失分别记入两个方向，颜色越深损失越多，对角线不计。统计不含护盾损耗和中立据点战损，始终展示当前已结算累计值，不混入历史选择或未来预测。公开汇总不改变地图及战斗详情的迷雾权限。

外交含公开、私聊、群聊，收件人由服务端验证。指挥官讨论是另一个私有通道，需要玩家确认才改变有效指令。通知与战报按当前授权过滤，历史分页不能当作新消息重复提醒。

实验室 OB 视角的聊天面板按时间展示全体玩家的公开、私聊和群聊，标明发送方、收件方和世界日，自动更新并支持加载更早消息。该入口只读，不领取玩家席位、不修改玩家已读状态、不包含指挥官私聊；全局聊天接口仅位于本机管理监听，认证玩家仍只能读取自己有权看到的频道。

玩家读取当前控制能力；允许人工命令时进入服务端人工优先级仲裁，不擅自结束 executor 租约。有效游戏行动由服务器自动记录签到，网页不再发送独立自动签到；AI 占席期间聊天遵守服务端控制限制，网页不提供额外 bot 接管/交还管理入口。

测试自动推进由服务端协调，页面只控制开关，不自行循环 step。关闭或多开页面不改变服务端速度。
