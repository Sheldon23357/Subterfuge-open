# 规则与证据限制

## 来源限制

固定客户端样本不包含完整线上服务器配置和动态更新。本地实现、参考公式及有限测试不能证明任意线上对局完全一致。原始专家资料属于研究记录，当前玩法已经移除该系统。

## 预测限制

玩家不能知道隐藏兵力分布、经济相位或尚未下达的命令。公开总量、可见状态和条件假设分别表达，未知不补零。预测提前终局和覆盖截断不能写成确定胜负或全域无解。

据点归属公开不代表兵力及护盾公开。舰队消失不能证明抵达、战败或死亡；实际结算须来自权威事实通道。资产耗尽预测也受这一限制，不能用缺少敌舰记录证明敌军已无舰队。

## 产品范围

组队、教程、自定义规则及隐藏操作按[功能范围](../development/feature-availability.md)处理。运行检查、浏览器检查、原版对照和隔离 bot 对局分别报告；单局结果不能证明整体策略强度。
