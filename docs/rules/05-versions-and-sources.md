# 规则来源与本地约定

## 当前规则与固定来源

当前运行参数为 data/profile-diplomacy-core-v1.json，入口为 packages/rules/src/index.ts。原始研究基线为 APK 12075 内置 rules 4300；样本信息见 research/provenance.json，哈希与定位见 data/build-manifest.json 和 data/sources.json。

原始参数、专家元数据和提取函数保留研究真实性，不代表当前玩法开放。研究入口 reference 与 reference-profile 不进入游戏及 bot 的活动依赖图。地图沿用固定几何算法，并在普通地图适配器中只创建初始据点。

## 当前本地约定

| 领域 | 约定 |
| --- | --- |
| 单位 | 普通据点与兵力舰队，出兵须携带正数兵力，目标只能是据点 |
| 淘汰 | 没有己方据点及携带兵力的存活舰队时淘汰 |
| 时间 | 1 tick 为 1 世界日，内部为 600 规则秒；现实推进按保存时钟映射 |
| 对局 | 新局个人阵营，teamSize=0；保留采矿、统治和最后幸存者终局 |
| 隐藏入口 | 资助、撤销资助、主动投降 |
| 地图 | 五个初始据点，共 160 兵；同局建筑组合一致，默认数量优先筛选 |
| 出兵与返航 | 普通出兵立即出发；每舰一次返航，兵力减半向下取整，敌占出发点正常攻击 |
| 身份与命令 | 授权、租约、版本、幂等与事务检查；人工操作保护与同日来源锁保留 |

规则与产品入口分别以[基础机制](01-core-rules.md)、[功能范围](../development/feature-availability.md)和当前源码为准。

## 来源维护

原版样本变化须重新提取并核对定位，不只替换数值；玩法调整维护当前共享参数和说明。旧开发存档失效时遵守项目存档约定，不添加通用迁移或补字段分支，不主动清空正常对局。研究与实际运行报告分别保存。
