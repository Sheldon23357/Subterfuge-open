# 战斗、事件排序与取整

本页描述当前无专家玩法。固定原版参数与技能资料仅供研究，不参与当前战斗结算。

## 普通战斗

进攻战力为舰队兵力；据点防守战力为守军加护盾；舰队之间交战没有护盾。

设进攻兵力 A、守军 D、护盾 S：

- 进攻剩余为 max(0, A-D-S)。
- 防守剩余为 max(0, min(D, D+S-A))。
- 护盾剩余为 max(0, S-A)。
- A 大于 D+S 时进攻获胜；相等时据点仍归守方，海上双方同兵则互灭。

没有技能先手、专家数量决胜、战后修复或俘虏转移。抵达敌方据点前召回其仍可召回的等待舰队，再结算实际守军；舰队与据点拥有者相同时卸载兵力。

| 条件 | 结果 |
| --- | --- |
| 进攻 27，守军 11，护盾 8 | 进攻剩 8，守军与护盾为 0，据点易主 |
| 进攻 5，守军 0，护盾 8 | 进攻为 0，护盾剩 3，守方胜 |
| 进攻 10，守军 10，无盾 | 双方兵力为 0，据点保持守方归属 |
| 海上 10 对 10 | 双方互灭 |

## Tick 内结算

1. 推进经济时钟，结算生产、护盾及开矿。
2. 更新普通舰队运动并收集出发、抵达和相遇事件。
3. 按步内时间和舰队槽位排序处理事件；抵达、碰撞与战斗使用当时状态。
4. 清理空舰队，完成经济后处理并检查不活跃状态。
5. 处理资产耗尽淘汰及采矿、统治、最后幸存者终局。

同一 tick 不固定先处理所有抵达或所有战斗；排序相同的事件保留稳定收集顺序。实际结算时间、命令时点与通知显示时间分别表达，见[世界时间契约](../development/world-day-time.md)。

## 开局加速与数值

生产、护盾与航速在 tick 不超过 72 时使用 1.5 倍开局加速，之后恢复正常；采矿使用自己的离散周期。

返航兵力向下取整；失矿库存使用非负数的 Math.round，即 floor(x+0.5)，不能直接换成银行家舍入。采矿周期保留非整数值。几何距离与航行保留原有浮点边界，不擅自改变计算精度或改用定点数。
